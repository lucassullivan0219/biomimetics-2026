步驟 4　模擬方法：BEMT 葉素動量理論（假設和參數全列）AI likely

做法

  1. 把槳葉從 r/R 0.15 到 0.995 切成 40 小段，越靠近葉尖切得越細。
  2. 每一段當成 2D 翼型，查它在當地攻角 α 和雷諾數 Re 下的升力係數 Cl、阻力係數 Cd。
  3. 同時要求「這一段產生的推力和扭矩」等於「流過這一圈的空氣動量變化」，解出每一段的入流角 φ。
  4. 把 40 段的推力、扭矩加起來，換成無因次的 CT、CP 和效率 η，跟 UIUC 實測比。

方程式

每一段只有一個未知數：入流角 φ。由軸向和切向動量守恆，加上 Prandtl 葉尖與輪轂損失 F：

σ′ = B·c / (2πr)　　Cn = Cl·cosφ − Cd·sinφ　　Ct = Cl·sinφ + Cd·cosφ
k = σ′·Cn / (4F·sinφ)　　k′ = σ′·Ct / (4F·sinφ)
殘差　R(φ) = Ωr / (cosφ + k′) · (sinφ − k) − V = 0

在 0 到 90° 之間找 R(φ) 第一次變號的地方，再用 Brent 法收斂到 10⁻¹⁰。這個寫法在 V = 0（靜止推力、無人機懸停）時也不會發散；常見的 a、a′ 寫法在 V = 0 時會除以零。AI likely

CT = T / (ρ n² D⁴)　　CP = P / (ρ n³ D⁵)　　J = V / (nD)　　η = J·CT / CP

為什麼要補升力

  • 槳葉在轉，離心力和科氏力會把槳根附近已經分離的氣流「壓回去」，讓失速延後、升力比 2D 風洞數據高。這叫旋轉失速延遲（Himmelskamp 效應）。REF QBlade 文件

公式（Snel 修正）

Cl₃D = Cl₂D + f · [ 2π·(α − α₀) − Cl₂D ]
f = 3.1 · λ²/(1+λ²) · g · (c/r)²　　λ = Ωr / V（懸停時 V = 0，λ²/(1+λ²) = 1）
g = 1（0° < α < 30°）；g = ½[1 + cos(6α − 180°)]（30°–60°）；其他 g = 0
  • 來源：Snel, Houwink & Piers 1993，公式取自 QBlade 文件；原始報告沒讀到。只修升力，不修阻力。REF

  • L18：Li 2018 的設計，齒深 = 弦長 10%、間距 = 弦長 20%。懸停時推力、扭矩、效率都量不出差別；前飛時升力、阻力都少約 5%。我用前飛的 −5% 當保守值。REFAI possible：選保守值
  • STE1：Candeloro 的小齒（齒寬 4 mm、齒高 3 mm、5 齒）。論文的 cT 用「削掉後的面積」計算，所以整槳推力要再乘面積比：(1 − 2.5%) × (1 − 2%) ≈ −4.5%。懸停遠場噪音跟基準一樣，前飛約 −2 dB。REFAI likely：換算方法
  • STE2：Candeloro 的大齒（6 mm × 6 mm、10 齒），是他們噪音最好的一支；整槳推力 (1 − 12%) × (1 − 10%) ≈ −21%。懸停只有槳盤面方向 −2 dB，其他角度反而更吵。REF
  • Candeloro 沒寫弦長；從論文「h/c = 0.58（h = 8 mm）」推回 c ≈ 13.8 mm，換算出 A/c、λ/c。AI possible

怎麼把文獻數據搬到 DA4002 上（每一步都是假設）

  1. 鋸齒段的位置：L18 放在 r/R 0.30–0.95（論文圖上整條尾緣都有齒，沒給數字）；STE1、STE2 照原槳「齒數 × 齒寬 ÷ 半徑」的比例（0.175R、0.525R），結束在 r/R 0.95（論文說葉尖附近最重要）。AI possible
  2. 實測換算（主要）：把文獻量到的整槳推力、功率變化全部算在鋸齒段上：Cl 乘 k_L = 1 + ΔT / f_T，Cd 乘 k_D = 1 + ΔP / f_P；f_T、f_P 是基準 DA4002（目前模型、5,000 RPM 懸停）上鋸齒段負擔的推力、功率比例。這個倍數已經包含齒被切掉的面積。AI possible
  3. 只算面積（對照）：鋸齒切進弦長，平均少掉齒深的一半，所以 Cl、Cd 都乘 (1 − A/c ÷ 2)，其他不變。不用任何擬合數字。AI possible
  4. 同樣的倍數用在每個攻角、每個雷諾數；零升力角和失速角不動（Snel 修正看到的 α₀、α_Clmax 不變）。AI possible
  5. ΔCd 0.0325 加在乘倍數之前（它代表單位面積的粗糙度阻力，面積少了它也跟著少）。AI likely

程式：sim/serrations.py（文獻數字和對應規則）、sim/serration_compare.py（比較，14 個平行 process，約 5 分鐘）。

解讀

  • 小鋸齒過關：齒深在弦長 10–22% 的兩組（L18、STE1），推力損失 3–5%，在標準以內；但原始模型下都很接近 5%，餘裕很小。SIM
  • BEMT 比文獻的整槳損失小：L18 給的是 −5%，模擬只掉 2.8%。原因：升力少一點 → 下洗速度變小 → 攻角變大 → 自己補回一部分。這是模型推出來的，沒有實測確認。SIMAI likely
  • 功率掉得比推力多：所以「同推力要多耗多少電」大約 0%（目前模型）到 +2%（原始模型），最高效率反而高 1–6%。這來自文獻的功率降幅本來就比推力大（Candeloro 的 STE2：cP −14%、cT −12%），不是鋸齒本身變有效率的證明。SIMAI possible
  • 過了推力標準，不代表過了噪音標準：我們的成功標準是「同推力下 −2 dB 以上」。文獻裡 L18 在懸停時高頻最多 −7.5 dB（低轉速時），轉速越高效果越小；STE1 懸停遠場沒有降噪。所以推力過關的兩組，懸停降噪能不能到 2 dB 不確定。REFOPEN：建議 L18 印出來給組員量，量 3,000–7,000 RPM 的總聲壓級和高頻段
  • 跟瘤突比：瘤突最好的一組推力少 6.1%（沒過），小鋸齒少 3%（過）。SIM

尾緣加厚：為了印得出來

  • DA4002 的 SDA1075 翼型在尾緣只有 0.13 mm 厚（弦長 11.5 mm），齒尖會比這還薄，印不出來。OBS 座標計算
  • 做法：鋸齒段的翼型後段加厚，讓尾緣（齒尖）= 0.4 mm（SLA 樹脂大約可印的下限，未查廠商規格）；加厚量從 x/c = 0.8 平滑增加到齒根 x/c = 0.9，之後固定；上下各加一半，弧線不變。齒根附近 0.63 mm、齒尖 0.40 mm。AI possible
  • 代價（NeuralFoil，Re 2 萬）：Cd 多 1–7%（例如 4°：0.0378 → 0.0397）；Cl 反而多 0.02–0.10（4°：0.588 → 0.637）。鈍尾緣有點像小擾流片（Gurney flap），一般會同時增加升力和阻力；但 NeuralFoil 是用 XFOIL 訓練的，XFOIL 對鈍尾緣後方的低壓區（底部阻力）算不準，所以阻力很可能被低估。SIMAI possible
  • 把加厚版的翼型數據放進 BEMT（再乘 L18 的倍數），推力 +2.0%（原始模型 +2.4%）、功率 +0.6%，比沒加厚的 L18 還好。這個「變好」很可能是假象；報告時應寫「在模型裡加厚不會讓推力損失超過 5%」，不要寫「加厚會增加推力」。SIMAI likely

流體模擬方法比較：先用 BEMT 快速篩選，再用 RANS 比較推力；噪音要準需要 LES 或 LBM
方法做法速度看得到鋸齒、瘤突嗎
BEMT 葉素動量理論把葉片切成很多小段，每段查 2D 翼型資料，再和動量守恆一起迭代求解幾秒只能間接放進去
渦粒子法 rVPM葉片簡化成一條線，尾流用帶渦量的粒子表示幾分鐘到幾小時只能間接放進去
RANS解時間平均的 Navier–Stokes 方程式，紊流用模型代替幾小時到一天看得到外形，看不到寬頻噪音
LES / DES直接解大尺度渦流，小尺度用模型代替幾天以上，要用叢集看得到
LBM 晶格波茲曼在格點上模擬粒子的碰撞和移動需要 GPU看得到，業界拿它當噪音的參考解
AI 代理模型用大量 CFD 結果訓練神經網路幾毫秒遇到訓練資料以外的新形狀就不準

模擬和現實的差距
  • 無人機槳屬於低雷諾數，流動會從層流轉成紊流，翼型資料和 RANS 在這裡誤差都很大（步驟 5 就遇到了）。AI likely
  • 3D 列印的層紋本身就是一種粗糙度，可能把鯊魚溝槽的效果蓋過去。AI likely
  • 真正飛行時的噪音，各種模擬方法都低估了（DLR 2026）。REF
  • 模擬通常只算槳本身；實際量測還會混進馬達和機架的聲音，以及房間的反射音。AI likely
