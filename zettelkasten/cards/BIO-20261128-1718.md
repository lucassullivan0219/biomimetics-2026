# Serration polars on the DA4002: small teeth (L18, STE1) lose 3-5 % hover thrust and pass the 5 % criterion in both models; large teeth (STE2) lose 12-20 % and fail

Putting each source's measured whole-rotor thrust and power change onto the serrated span as Cl and Cd factors, L18 loses 2.8 % (uncorrected 4.7 %), STE1 3.1 % (4.5 %) and STE2 12.1 % (19.9 %) hover thrust at 5000 RPM; power drops more than thrust, so equal-thrust power is about unchanged; a TE thickened to 0.4 mm for printing gives +2 % in NeuralFoil, probably an artefact.

模擬：Claude，2026-11-28，DESKTOP-UURUTP1；`uv run python sim/serration_compare.py`（14 個平行 process，5 分 22 秒）；BEMT + NeuralFoil large，n_crit 3；「目前模型」= Snel（上限 1）+ ΔCd 0.0325，「原始模型」= 只有 n_crit 3。輸出 `sim/out/serrations_compare.json|png`。

## 解讀
- 判定（AGREED 2026-11-25 的「推力損失 < 5%」）：L18、STE1 在兩個模型、兩種對應下都過；STE2 都沒過（SIM）。原始模型下 L18 −4.7%、STE1 −4.5%，餘裕只有約 0.5%。
- BEMT 的損失比文獻整槳值小（L18 −5.2% → −2.8%）：升力減 → 誘導速度減 → 攻角增，自己補回一部分（AI likely）。
- 功率降得比推力多 → 同推力功率約 0%（目前）到 +2%（原始）；η_max 上升 1–6%。這來自文獻的 ΔP 本來就比 ΔT 大，不是新證據（AI possible）。
- 加厚尾緣讓 Cl 上升（鈍尾緣類似 Gurney flap 效應）且 Cd 只升 1–7%；NeuralFoil/XFOIL 對鈍尾緣底部阻力可能低估，+2% 推力很可能是假象（AI possible）。報告時只說「不會讓推力損失超過 5%」。
- 推力過關 ≠ 噪音過關：L18 懸停高頻最多 −7.5 dB（低轉速）、STE1 懸停遠場 0 dB（REF，BIO-20261128-1712）。同推力 −2 dB 要靠組員實測（AGREED 2026-11-25）。

## OPEN
- 噪音：建議把基準槳和 L18（列印版）用 SLA 印出來，量 3000–7000 RPM 的 OASPL 與 6 kHz 以上頻段。
- 組合：槳根瘤突（BIO-20261128-1315 的 OPEN）＋外段鋸齒，建議下一輪用 `Rotor.polar` 每段不同 polar 一起跑。
