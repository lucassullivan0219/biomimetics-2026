# Baseline BEMT validation against UIUC DA4002 5x3.75: thrust within ~5-7 % in the tunnel, power 14-28 % low

With NeuralFoil n_crit=3 the BEMT thrust matches UIUC wind-tunnel data within about 5-7 % and static thrust within 13.5 %, but power is under-predicted by 14-28 %, so absolute efficiency is too high; good enough for baseline-vs-bionic comparisons, not for absolute numbers.

## 基準槳選擇（AI likely，Claude 2026-11-26；使用者「照建議」授權執行）
DA4002 5x3.75：UIUC 自己設計並 **3D 列印**的 5 吋雙葉槳；矩形槳葉 c/R = 0.18，整支 SDA1075 翼型（12% 厚），p/D 0.75（75% 處 17.7°）。
理由：幾何與翼型全部公開（其他市售槳翼型不明）、尺寸＝小型空拍機、有靜止與風洞數據、和組員之後要 3D 列印實測的條件相同。
來源（REF）：Deters, Ananda & Selig 2014, AIAA 2014-2151, https://m-selig.ae.illinois.edu/pubs/DetersAnandaSelig-2014-AIAA-2014-2151.pdf （SDA1075 座標在附錄 Table 4，已存 `sim/data/sda1075.dat`）；數據 UIUC Propeller Database Vol. 2, https://m-selig.ae.illinois.edu/props/volume-2/propDB-volume-2.html

## 模擬設定
- 程式：`sim/bemt.py`（單一未知數 φ 的 BEMT，Prandtl 葉尖＋輪轂損失）、`sim/validate_da4002.py`
- 極曲線：NeuralFoil 0.3.3 large，α −15°…25°（0.5° 間隔）× Re 3e3…2e5（16 點對數）
- 幾何：UIUC 量測的 as-tested `da4002_5x3.75_geom.txt`，40 個 stations（r/R 0.15–0.995，靠葉尖加密），輪轂損失 r/R 0.10
- 空氣 ρ 1.225 kg/m³、ν 1.48e-5 m²/s
- 執行：Claude，2026-11-26，DESKTOP-UURUTP1
- 誤差 = 模擬平均相對誤差；風洞只計 CT > 0.03 的點

## 解讀
- n_crit = 9（XFOIL 預設、安靜風洞）：Re 1–3 萬的翼型被算成大面積層流分離（Re 1e4、α 4° 時 Cl 0.22、Cd 0.059），推力少一半。旋轉槳＋3D 列印粗糙面轉捩較早，n_crit 3 較合理（AI likely）。**採用 n_crit = 3 作為目前基準。**
- CP 在每個 J 都少約 0.015 → 型阻被低估（NeuralFoil 低 Re Cd 偏低、未計列印粗糙度、槳轂阻力），因此 η 高估約 0.03–0.06（AI likely）。
- 靜止時實測 CT 幾乎不隨 RPM 變（0.12–0.13），模擬從 0.093 升到 0.120 → 模擬的低 Re 效應過強；槳根 α 約 25°（失速區），且沒有旋轉失速延遲修正（AI likely）。
- 用途：比較「仿生 vs 基準」的相對差異可用（同一套誤差大致相消，AI possible），絕對推力和功率不可直接當結論。

## 下一步（OPEN，建議）
