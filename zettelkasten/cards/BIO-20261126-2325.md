# Modeling skill search: aero skills make no 3D geometry, so text-to-cad's cad skill was used

The user asked for an online modeling skill, preferably aero/fluid-specific, else at least teardown; the aero skill found only computes planform numbers, so the general text-to-cad cad skill (build123d) was used.

使用者原話（2026-11-26）：「網站附上可全螢幕可放大可旋轉的精細3D模型，搜尋網路上的建模 skills不要自己亂做，有專門給流體相關或飛行器的最好，都沒有的話至少用 teardown。」

| 候選 | 類型 | 結果 |
|---|---|---|
| ashfordeOU/aero-agent-skills `openvsp-geometry`（Apache-2.0，10 星） | 飛行器專用 | OBS：SKILL.md 只算翼面積、AR、MAC、浸濕面積等數字，不產生 3D 幾何 → 不適用 |
| 同包 `propeller-sizing` | 飛行器專用 | 只做尺寸估算（依路徑名稱判斷，未讀內容） |
| earthtojake/text-to-cad `cad`（MIT，27,520 星，2026-11-26 仍更新） | 通用 CAD | build123d 參數化實體；STEP/STL/3MF/GLB 匯出；`cad model dfm` 列印檢查 → **採用** |
