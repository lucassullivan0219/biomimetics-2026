# Corrigan-Schillings stall delay is slightly worse than Snel on every metric; neither fixes the static thrust trend

With the same refit drag offset (0.0325), the Corrigan-Schillings model trails Snel on all checks, and both leave the same rise of static thrust error with RPM, which points at the airfoil data rather than the stall-delay model; Snel + dCd stays the current model.

使用者原話（2026-11-27）：「先試另一個升力模型」

## 公式（REF）
K = (0.1517/(c/r))^(1/1.084)；Δα = (α_Clmax − α0)·[(K·(c/r)/0.136)^n − 1]，n = 1（Corrigan：0.8–1.6，1 適用多數）。
套用：α ≤ α_j 不變；α_j < α ≤ α_j+Δα 時 Cl 以 0.1/deg 線性延伸、Cd 停在 Cd(α_j)；之後 Cl = Cl2D(α−Δα) + 0.1Δα、Cd = Cd2D(α−Δα)（升力延伸＋低阻區變寬）。α_j ≈ 6°。
來源：Tangler & Selig 1997, WINDPOWER '97, https://m-selig.web.engr.illinois.edu/pubs/TanglerSelig-1997-Windpower-StallDelay.pdf （Claude 2026-11-27 用 pypdf 讀 PDF 隱藏 OCR 層；web-fetch 讀不到）；原始 Corrigan & Schillings 1994, AHS Aeromechanics Specialists Conf.（未讀）。論文自述限制：假設 3D 失速後形狀與 2D 相同，「questionable」。
選它的理由：Aeronautical Journal 低 Re BEMT 比較中 CS 最好（REF，只讀摘要，BIO-20261127-0044）。

## 核對（OBS，`sim/test_stall_delay.py`）
論文 Table 1（α_Clmax 9°、α0 −1.2°）10 列：Δα 全在 6% 內，最大差 0.167°（c/r = 1）。差距來自表上 K 在大 c/r 時比印出公式高約 1%（AI possible：從 Fig. 2 讀圖）。照公式實作。

## 我的假設
- α_Clmax：第一個 Cl 峰值；無峰值（NeuralFoil 在 Re < 1e4 一路上升）時取斜率降到最大斜率 30% 處（AI possible）。最靠槳轂一段 Re 2,681 找不到 → 退回 25°，Δα 6.95°；其他段 1.4–2.1°（SIM 5000 RPM）。
- α0 同 Snel；升力斜率 0.1/deg（REF）。

敏感度（無 ΔCd）：n 1.6 → 靜止 CT +4.1%；α_j 4° / 8° → 風洞 CT 平均 −3.4 / −4.9%（主要設定 −4.1%）。

靜止 CT 誤差隨轉速（原始 / Snel / CS）：1410 RPM −21.4 / −7.1 / −6.2%；4967 RPM −10.7 / +2.5 / +1.1%；7440 RPM −6.8 / +5.6 / +4.5% → 三者斜率相同。

## 解讀
- CS 不比 Snel 好；部分原因是 CS 拉寬低阻區、功率更低（AI likely）。
- 靜止 CT 趨勢與失速延遲模型無關，來自翼型數據的 Re 效應（AI likely）；要確認需低 Re 風洞數據（OPEN）。
- 決定：維持 Snel + ΔCd 0.0325；CS 留作對照（`--cs`）（AI likely）。
